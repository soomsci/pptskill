# 전환·애니메이션 설계와 구현

이 문서는 오프라인 실행 규칙이다. 아래 출처를 매번 열지 않는다.

## 원본과 추가 효과의 구분

회색·주황색 원본 PPTX 10장 중 2–10장에 `fade` 전환과 `spd=fast`가 들어 있고 1장에는 전환 노드가 없다. 초 단위 시간은 이 속성에 기록되어 있지 않다. 개별 객체 `p:timing` 노드는 10장 모두 없다. 이것은 제공된 PPTX의 사실이며 Canva 원본에 모든 객체 효과가 없다는 증거는 아니다.

아래 시간·등장 순서는 사용자의 애니메이션 요청에 따라 스킬에 추가한 연출 기본값이다. 원본에서 추출한 효과라고 말하지 않는다. 청회색 PPTX 13장에는 전환과 객체 timing 노드가 모두 없다. 따라서 청회색의 아래 효과는 추가 연출이다. PPTX 내보내기에서 Canva 효과가 누락될 수 있으므로 Canva 전체에 효과가 없다고 단정하지 않는다.

## 모드

- `presenter` 기본: 발표자가 클릭해 다음 의미 묶음을 공개. 페이지 자동 넘김 없음. 첫 화면부터 배경·프레임·헤더·클립·출처는 보인다.
- `static`: 읽기용/PDF/애니메이션 없음 요청. 모든 정보 표시, 전환·등장·반복 효과 없음.
- `reduced`: 이동·확대·모핑 없이 짧은 페이드 또는 즉시 표시. 내용 순서는 유지하되 필요하지 않은 클릭은 제거.
- `autoplay`: 영상·무인 발표를 명시했을 때만. 음성 또는 실제 읽기 시간에 맞춰 체류 시간을 정하고 마지막 효과 뒤 읽을 시간을 둔다. 임의의 일괄 5초 설정은 하지 않는다.

## 스타일별 동작 토큰

| 속성 | 회색·주황 | 청회색 종이 프레임 |
|---|---|---|
| 페이지 전환 | fade 0.35초 | fade 0.45초 |
| 제목 등장 | fade 0.30초 | fade 0.40초 |
| 본문 묶음 등장 | fade 0.25초 | fade 0.35초 |
| 묶음 안 순차 간격 | 0.08초 | 0.10초 |
| 의미 있는 선·진척 드러내기 | 방향성 wipe 0.45초 | 방향성 wipe 0.50초 |
| 강조 | 강조색 또는 옅은 배경 1회 | 옅은 청회색 강조 1회 |
| 기본 금지 | 회전·바운스·글자별 타자·깜빡임·소리·무한반복 | 동일 |

기본값이며 설명의 속도에 맞춰 조정한다. 제목과 본문 전체를 매번 천천히 등장시키지 않는다. 장당 클릭 묶음은 보통 1–3개; 교육 절차 등 실제 단계가 더 많으면 늘릴 수 있다. 배경과 장식을 따로 움직여 내용을 방해하지 않는다.

## 장별 시퀀스

| 내지 | 처음부터 보이는 것 | 이후 등장 순서 |
|---|---|---|
| 표지 | 공통 프레임·메타정보 | 제목 자동 fade → 밑줄 두 개 한 묶음 wipe 또는 두 번째 제목 줄 fade → 부제 fade |
| 목차 | 제목·모든 항목 | 현재 절만 강조. 목차 전체에 불필요한 클릭을 요구하지 않음 |
| 요약·전략·목록 | 제목·구분 구조 | 의미 행 단위 클릭 등장. 행의 배경·체크·문장을 함께 처리 |
| 카드·4분류 | 제목 | 카드 전체를 한 묶음으로, 설명 순서대로 클릭. 카드 안 문장·아이콘을 개별로 흩어지게 하지 않음 |
| 사진+설명 | 제목·사진·캡션 | 우측 요지와 설명 함께 fade. 사진의 지속 확대·패닝은 기본으로 넣지 않음 |
| 사진 앨범 | 사진과 제목 전체 | 비교할 대상만 강조. 나란히 비교해야 하는 사진을 서로 다른 시간에 숨기지 않음 |
| KPI | 지표명·기간·출처 | 각 지표의 실제 값·단위·변화율 함께 fade. 0부터 숫자 카운트업으로 가짜 중간 수치를 보여주지 않음 |
| 차트 | 제목·축·단위·범례·출처 | 비교에 필요한 계열은 함께 등장. 설명상 필요하면 계열 단위. 데이터 점 하나씩 불필요하게 지연시키지 않음 |
| 진행률 | 라벨·트랙·정확한 값 | 막대 wipe; 값은 실제 최종값을 유지. wipe가 지원되지 않으면 fade |
| 타임라인 | 전체 기준선·단계 번호 | 클릭마다 해당 노드+제목+설명. 진행 방향의 연결선은 선택적으로 wipe |
| 표 | 표 전체 | 설명 중인 행에 선택적 얇은 강조 표시. 셀 하나씩 등장시키거나 표를 이미지로 변환하지 않음 |
| 설명+비교 | 제목·상단 분석 | 하단 비교 카드들은 동시 또는 두 번째 클릭에 함께 등장 |
| 마무리 | 프레임·연락처 | 제목 한 번 fade, 반복 없음 |

## 실제 구현 계약

효과 계획만 적고 애니메이션을 적용했다고 보고하지 않는다. 제작 전에 사용 도구가 전환·객체 애니메이션을 실제 저장할 수 있는지 확인한다. 지원 API 또는 대상 앱의 애니메이션 패널로 구현한다. 객체에 안정적인 이름을 주고 장별 `대상 / 효과 / 시작 / 시간 / 지연 / 클릭 묶음`을 기록해 적용 결과와 대조한다.

PowerPoint의 `On Click`은 새 클릭, `With Previous`는 앞 효과와 동시 시작, `After Previous`는 앞 효과 완료 후 시작이다. 한 카드의 요소는 그룹 또는 같은 클릭 묶음으로 묶는다. 지연은 선택된 시작 기준으로 계산한다. 네이티브 차트·표의 편집성을 보존한다.

Canva에서는 현재 편집기의 지원 효과를 대응시킨다. Canva 효과가 PPTX에 그대로 옮겨졌다고 가정하지 않는다. 최종 대상이 PowerPoint이면 내보낸 PPTX에서 효과를 확인하고 필요한 효과를 다시 적용한다. 사용할 수 없는 유료 효과에 의존하지 않는다.

효과를 지원하지 않는 제작 도구만 있다면 지원하는 도구로 전환한다. 그것도 불가능하면 편집 가능한 정적 덱과 미적용 효과 목록을 전달하고 애니메이션 미적용을 명시한다. 요청된 장수를 늘리는 단계별 복제 슬라이드는 기본 대체법이 아니다. MP4는 움직임을 담지만 편집 가능한 PPTX의 대체물이 아니다.

## 검수

정적 PNG만으로 효과 적용을 판정하지 않는다. 대상 앱의 슬라이드 쇼에서 첫 상태·각 클릭 후 상태·최종 상태와 다음 장 진입을 확인한다. 클릭 횟수, 제목이 가려지는 순간, 빈 화면, 조기 자동 넘김, 겹침·잘림, 이전 장으로 돌아왔을 때 상태를 본다. 저장 후 재열어 재생이 유지되는지 확인한다.

PDF·인쇄용은 애니메이션이 없는 최종 완성 상태로 내보내서 모든 내용이 보이는지 검사한다. 시간·클릭 동작을 검수하지 못했다면 그 범위를 명시한다.
