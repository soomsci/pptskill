# 내장 원본 요소 사전

## 읽는 순서

일반 제작은 디자인 토큰과 레이아웃 명세를 쓴다. 특정 요소나 원본에 가까운 배치가 필요하면 아래 인덱스에서 해당 장의 `detail_path`만 연다. 모든 상세 파일을 한꺼번에 문맥에 넣지 않는다.

- [회색·주황색 원본 인덱스](../assets/template-elements/gray-orange/inventory.json): 10장, 말단 객체 204개, 그룹 71개, 미디어 8개.
- [청회색 원본 인덱스](../assets/template-elements/blue-gray/inventory.json): 13장, 말단 객체 262개, 그룹 69개, 미디어 22개.
- [로컬 자산 미리보기](../assets/template-elements/index.html): 네트워크 없이 이미지·벡터를 확인한다.

말단 객체는 텍스트를 포함한 도형, 이미지, 그래픽 프레임, 연결선의 수이며 그룹은 별도다. PNG와 SVG 대체 이미지가 같은 그림을 표현하는 경우도 있어 30개 미디어가 서로 다른 그림 30종을 뜻하지는 않는다.

## 실제 포함 정보

각 장의 `object_tree`에 원본 XML의 요소 순서·그룹·객체 ID·이름·도형 경로·좌표·회전·뒤집기·채우기·투명도·선·그림 효과·이미지 자르기·본문 여백·문단 정렬·행간·문자별 글꼴·크기·굵기·색·표 셀 속성을 트리로 보관했다. 원본에 존재하는 속성만 들어 있다. 이미지 관계는 `relationships`, 효과는 `transition`과 `timing`에 있다. 기본값이나 테마에서 상속하는 속성은 트리에 직접 지정되지 않을 수 있다.

좌표는 EMU다. 914400 EMU = 1인치. 원본 캔버스는 18288000×10287000 EMU, 즉 20×11.25인치다. 정규화 좌표는 원본 전역 EMU에 1280/18288000을 곱한다. 그룹의 자식 좌표를 전역 좌표로 바로 취급하지 않는다. `chOff`를 빼고 `ext/chExt` 비율로 확대·축소한 뒤 부모 `off`를 더하며, 부모의 회전·뒤집기까지 합성한다. 회전은 60000단위가 1도다. 겹침 순서는 원본 트리의 순서를 보존한다.

원본 서체가 있으면 해당 서체와 크기를 쓰고, 없으면 내장 대체 서체로 바꾼 뒤 텍스트를 검수한다. 원본 폰트 파일은 포함하지 않는다. 큰 캔버스의 pt 값을 작은 캔버스에 그대로 쓰지 않는다. 예문 텍스트는 새 원고로 교체한다.

## 효과와 그룹

공통 프레임·질감·클립·헤더는 고정한다. 카드 배경·아이콘·텍스트를 같은 의미 묶음으로 등장시키고, 비교표·사진은 함께 봐야 하는 범위를 동시에 보인다. [motion.md](motion.md)의 원본 확인 결과와 추가 연출을 따른다.

## 자산 출처와 범위

이 자산은 사용자가 지정한 두 템플릿의 PPTX에서 추출한 것이다. 기존 v4의 별도 사진·디자인 아틀라스는 포함하지 않았다. 템플릿 자산을 CC0나 새로 제작한 그림이라고 표시하지 않는다. 원본의 예시 사진·이름·날짜·성과·웹 주소는 디자인 견본이며 사용자의 실제 자료가 아니다.

현재 기록은 PPTX 내보내기에 포함된 모든 슬라이드 객체와 미디어를 대상으로 한다. Canva에만 남아 있고 내보내지 않은 기능·폰트 바이너리·편집기 이력까지 포함했다는 뜻은 아니다. 새 템플릿을 명시적으로 갱신할 때만 [추출 도구](../scripts/extract_template.py)를 로컬 PPTX에 실행한다. 일반 제작에서는 재추출·다운로드가 필요 없다.
