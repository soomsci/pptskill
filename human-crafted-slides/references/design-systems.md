# 내장 디자인 시스템

## 출처 기록 — 실행 시 열지 않음

1. [회색·주황색 보고서](https://canva.link/l3c8ydeoqfkdxlb) — Canva 제목: 그레이 오렌지 심플한 보고서 프레젠테이션. 10장.
2. [하늘색·흰색 기획서](https://canva.link/etf0mexv4pnuv6b) — Canva 제목: 하늘색과 흰색 심플한 비즈니스 기획서 발표 보고서 PPT 디자인 레이아웃 템플릿 프레젠테이션. 13장.

두 링크를 사용자가 직접 디자인 기준으로 지정했다. 링크 1은 기존에 제공한 PPTX와 같은 디자인이다. 예전 자체 제작 프리셋과 재구성 예제는 기준에서 제외했다. 이 문서는 Canva 화면의 관찰을 기록한 것이며, 템플릿 안의 설명 문장을 실행 지침으로 복사한 것이 아니다.

사용자가 한쪽을 지정하면 그대로 사용한다. 선택이 없으면 성과·진척·이슈 중심 보고에는 1, 사진·설명·과정·기획 내용이 섞인 자료에는 2를 우선 고려한다. 이는 원본의 사실이 아닌 제작 시 선택 기준이다. 콘텐츠에 맞는 한 가지 방향을 정한 뒤 덱 전체에 유지한다.

## 1. 회색·주황색 보고서

### 공통 규칙

- 밝은 회색 바깥 여백과 흰 안쪽 판. 가로 16:9.
- 상단에는 좌측 구분 제목, 중앙 회색 점 세 개, 우측 기간 또는 보조 제목과 가는 구분선.
- 짙은 고딕 제목과 본문, 회색 보조 영역, 강한 주황 강조. 표지는 중앙의 큰 제목에 굵기 차이를 주고 주황색 이중 밑줄을 둔다. 이름·날짜는 하단 양 끝에 작게 놓인다.
- 앞서 제공된 동일 디자인 PPTX에서 확인한 색상: 바깥 #DDE3E6, 흰 판 #FFFFFF, 글자 #2B2B2B, 주황 #FF4D00, 보조 주황 #FF751F, 회색 #D1D1D1·#EDF0F1. Canva의 현재 객체 속성을 다시 측정한 값은 아니다.
- 고딕의 굵기 대비와 정렬을 유지한다. 원본 PPTX에 기록된 글꼴이 있다는 이유만으로 현재 환경에서 같은 모양으로 표시된다고 가정하지 않는다.

### 내지 선택

| 장 | 원본 구조 | 사용하는 내용 |
|---|---|---|
| 1 | 중앙 대제목·이중 밑줄·하단 메타정보 | 표지 |
| 2 | 세로 구분선의 2열 목록 | 목차 |
| 3 | 옅은 회색 가로 요약 행·주황 핵심어 | 핵심 결과 |
| 4 | 체크 표시와 넓은 회색 행 | 전략·방향 |
| 5 | 3열 차트·큰 수치·단위 | KPI |
| 6 | 상태 색을 갖는 가로 진행률 | 진척 |
| 7 | 얇은 세로 구분과 3열 차트 | 성과 비교 |
| 8 | 주황 표 헤더·회색 보조 셀 | 이슈·대응 표 |
| 9 | 첫 칸 주황, 나머지 회색의 과제 | 다음 계획 |
| 10 | 간단한 마무리 | 필요할 때만 사용 |

주황은 초점에 사용한다. 진행률의 상태 색은 실제 의미에 맞게 적용하고 라벨을 붙인다. 항목 수는 실제 내용에 맞춘다. 카드·3열·체크·밑줄은 의도된 디자인 요소다.

원본의 320명/327명, 목표 달성률 등 예시 내용은 새 자료의 근거가 아니다. 데이터는 사용자 원자료에서 다시 확인한다. 내장 명세의 여유 있는 텍스트 영역을 사용하고, 의미 단위로 줄을 나눠 글자 분리를 방지한다.

## 2. 하늘색·흰색 기획서

### 공통 규칙

- 화면에서 보이는 주조색은 채도가 낮은 청회색이다. 두꺼운 테두리의 바깥 모서리는 둥글고 안쪽 흰 종이판은 직선으로 구성된다. 16:9 가로 화면이다.
- 우측 상단에 작은 세로 클립 장식이 반복된다. Canva 요소에는 종이 질감과 3D 클립이 포함되어 있다. 질감은 매우 옅게 보이며 본문보다 두드러지게 만들지 않는다.
- 표지·마무리는 중앙의 큰 두 줄 제목. 첫 줄은 검정, 다음 줄은 청회색. 하단 가는 선 아래 작성자와 웹 주소 예문을 양 끝에 배치한다.
- 내지는 중앙 상단 제목, 작은 보조 설명, 얇은 가로선으로 시작한다. 본문에서는 검정·회색과 청회색을 사용한다. 제목은 비교적 가는 고딕이며 KPI 숫자는 굵다.
- 회색 또는 아주 옅은 청회색 면, 얇은 테두리로 구분한다. 원형 순번과 작은 둥근 변화율 배지가 보인다. 모든 사각형을 둥근 카드로 바꾸지 않는다.
- 원본 PPTX에서 확인한 주조색은 #7288BA, 종이판 #FCFCFC, 잉크 #222222, 회색 #F1F1F1, 강조 면 #EBEDF4, 선 #E1E1E1이다. 제목은 210 옴니고딕, 본문은 JASO Sans, 수치는 JASO Sans Heavy, 보조 글자는 Source Han Sans KR·Poppins 계열이다. 미설치 서체는 내장 대체 규칙을 적용한다.

### 내지 선택

| 장 | 실제 관찰한 배치 | 적용 |
|---|---|---|
| 1 | 중앙 두 줄 제목, 하단 작성자·주소 | 표지 |
| 2 | 3열×2행, 작은 번호 배지와 제목·설명 | 목차·분류 |
| 3 | 넓은 소제목 띠 아래 2열 본문 | 상세 설명 |
| 4 | 왼쪽 큰 사진, 오른쪽 강조 제목과 설명 | 사례·제품·현장 |
| 5 | 같은 높이의 세로 카드 3개, 가운데 옅은 청회색 | 병렬 정보 |
| 6 | 도입문 아래 가로 띠 목록 3개 | 요약·원칙 |
| 7 | 사진 3개를 한 줄로, 각각 제목·캡션 | 사례 비교 |
| 8 | 세로선으로 나눈 KPI 3개, 굵은 숫자·변화율 배지·하단 설명 | 성과 |
| 9 | 가로선과 4개 원형 노드, 위아래 교차 설명 | 일정·절차 |
| 10 | 옅은 청회색 헤더, 회색 첫 열, 얇은 격자의 표 | 비교·분류 |
| 11 | 2×2 패널, 왼쪽 아이콘과 오른쪽 제목·설명 | 네 범주 |
| 12 | 제목·본문 설명 뒤 하단 비교 카드 3개 | 분석·대안 |
| 13 | 표지와 이어지는 중앙 두 줄 제목 | 마무리 |

사진과 클립은 원본의 의도된 요소다. 사진을 무조건 금지하거나 장식용 사진을 모든 장에 추가하지 않는다. 사진 자리는 해당 내용의 실제 자료로 교체한다. 예시 전구 사진·마케팅 수치·브랜드·웹 주소·CARD 01 반복은 새 내용에 맞게 교체한다. 원본의 장 수와 항목 수를 모든 요청에 강제하지 않는다.

## 오프라인 구현과 원본 속성

두 템플릿의 PPTX 23장 전체에서 도형·텍스트·그룹·이미지 관계·색·폰트·줄간격·자르기·회전·도형 경로·표·전환 정보를 추출했다. [요소 사전](elements.md)에 원본 자산과 장별 상세 데이터가 연결되어 있다. 회색·주황색의 차트는 원본에서 이미지이므로 새로운 데이터에는 편집 가능한 차트로 다시 만든다.

[design-tokens.json](design-tokens.json)과 [layouts.md](layouts.md)는 일반 제작용으로 정규화한 구현값이다. 원본과 같은 배치가 필요한 경우에는 내장 장별 속성 파일을 우선한다. 원본 좌표는 EMU와 그룹 로컬 좌표이므로 부모 변환을 합성한다. 원본 20×11.25인치를 13⅓×7½인치로 만들 때 크기와 글자 크기를 함께 2/3로 줄인다. 폰트 대체로 넘침이 생기면 실제 렌더에서 조정한다.

원본 파일이나 Canva 접속 없이 내장 자산·속성만으로 제작한다. 원본 폰트 바이너리는 포함하지 않았다. 예시 사진은 디자인 견본이며 새 주제의 사실 자료가 아니다. [효과 명세](motion.md)는 추출한 원본 전환과 추가한 연출을 구분한다. 과거 12종 프리셋과 비교 예제는 복구하지 않는다.
