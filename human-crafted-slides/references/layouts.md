# 내장 레이아웃 구현 명세

## 좌표와 공통 적용

모든 좌표는 1280×720 기준의 `[x,y,w,h]`다. 선은 `[x1,y1,x2,y2]`. 토큰의 공통 프레임·헤더를 먼저 만든 뒤 아래 객체를 본문 영역에 놓는다. 출력 비율은 16:9, 기본 크기는 13⅓×7½인치다. 폰트 pt는 해당 크기 기준이며 좌표 단위와 혼동하지 않는다. 텍스트는 상단 정렬, 제목·숫자는 명시한 경우 중앙 정렬이다.

아래 영역은 텍스트 상자 경계이며 글자 크기는 토큰의 역할값을 쓴다. 행간은 1.15–1.3, 소제목 뒤 간격 8–12 단위. 이 정규화 값을 시작점으로 사용한다. 원본의 정확한 객체별 배치는 요소 사전의 내장 상세 파일에 있다. 실제 문구에 따라 안쪽 위치·줄 수를 조정하되 프레임·주요 정렬은 유지한다.

## 내용량 조정

글자가 넘치면 중복 문구 정리 → 의미 단위 행갈이 → 해당 영역 확대·재배치 → 사용자가 허용한 장 분리 순으로 해결한다. 본문을 14pt 미만으로 줄여 넣는 것을 기본 해결법으로 삼지 않는다. 표·캡션은 별도 역할 크기를 적용하되 읽힘을 렌더로 검증한다. 지정 장수가 있으면 그 안에서 정보 배치를 조정하고 중요한 조건을 삭제하지 않는다.

내지의 항목 수와 원본 장 수는 강제 규칙이 아니다. 사진·수치·일정이 없으면 만들어 채우지 않는다. 구도 다양성은 이 목록에서 실제 정보 관계에 맞는 내지를 선택하는 것으로 만든다.
